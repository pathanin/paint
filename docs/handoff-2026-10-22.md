2. **Fixed findings 1–3** (`c56df80`). How it works now:
   - **Document identity.** `S.docId` (`state.js`) is bumped by New (`doc.js` `newDoc`) and Open (`fileio.js` `loadFile`). Work that waits checks it, because New and Open reuse the base canvas and clear the history, so `base` and `hist.top()` can't tell documents apart.
   - **Save** (`fileio.js` `saveNow`):
     - It is cancelled if the document was replaced before the encode.
     - After the write, it leaves the new document its own handle, name and save point.
     - `encodeBlob()` (`libs.js`) takes a `still` callback. Its fallback, which encodes the live canvas when the blob worker fails, then refuses to encode a replaced document.
   - **Resize** (`transforms.js` `scaleDoc`): a result that arrives after New or Open is dropped.
   - **Open ordering** (`doc.js` `requestDoc` / `landDoc`, `fileio.js` `loadFile`, `paste.js` drop):
     - Requests to replace the document are numbered: New, an Open once it has its file, a drop as it arrives.
     - An Open still loading when a *later* request *lands* is dropped quietly.
     - A later request that never lands leaves it alone: a file that won't decode, one too big, or a discard the user declined.
     - If the document was edited while an Open loaded (`docMark()`), the user is asked about discarding again.
   - **⌘E on a selection** (`core.js` `clearsUnder` / `flattenRuns`, `objects.js` `flattenSelected`):
     - A mark that clears or replaces what is under it stays an object: Transparent strokes and patches, and fills that replace pixels.
     - It splits the images where it overlaps them, and a toast says why.
   - **Docs updated:** `CLAUDE.md` (the `S` description), `task.md` (Decisions: "Dialogs and saving" and "Shapes"), `docs/total-objects.md`.

## How to run things

- **Build:** `npm run build`. The e2e scripts test `dist/` on http://localhost:8765/. During this work, a `python3 -m http.server 8765 -d dist` was already running; otherwise use `npm run serve`.
- **Suites:** `node test/e2e/<suite>.js`. Use `BROWSER=webkit` for WebKit. smoke, history, preview, filledge, objects, alpha and libs run in both engines; pwa runs in Chrome only.
- **Repro scripts:**
  - Example: `node docs/code-review-2026-10-21/repro.js http://localhost:8765/ [case,…]`.
  - They print observed values and assert nothing.
  - On this branch, the cases for findings 1–3 now print the fixed behaviour; on `origin/master` they print the bugs.
  - `ROOT=<dist dir>` serves another build without a server.
